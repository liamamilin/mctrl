# 评估规范：结构、使用、效果与迁移

评估回答具体问题，不给整套体系一个没有依据的总分。先确定任务、主体、当前状态、判断规则、材料与成本，再选择测量。输出清楚仅是候选改善的一种证据。

基线是操作前的比较材料；归因是判断变化是否由指定操作带来；保持是延迟后仍能运用；迁移是在不同材料或情境中运用。独立表现指没有由协助者直接提供所测答案的表现。[证据与学习术语](../GLOSSARY.md#evidence-terms)列出有关边界。

## 四类问题

| 问题 | 材料和方法 | 能支持什么 | 不能支持什么 |
| --- | --- | --- | --- |
| 结构是否一致？ | ID、依赖、定义、边界案例、链接和构建检查 | 文档一致、接口可追溯、已知混淆有处理出口 | 实际干预效果 |
| 本次任务是否可用？ | 前后产物、实际判断／行为、错误、完成时间、使用者负担 | 对特定任务的局部可用性 | 跨任务一般能力 |
| 是否由该操作带来改善？ | 适当比较条件、随机或其他可论证设计、预先指定结果、保留失败 | 在研究条件下估计效果与代价 | 一切对象、媒介和时长均有效 |
| 是否保持并迁移？ | 延迟测量、陌生任务、减少提示、独立表现 | 指定条件下的保持／迁移 | 永久能力、无限迁移 |

## 按目标选择主检查

| 目标 | 主要可观察检查 | 常见伪成功 |
| --- | --- | --- |
| 表征澄清 | 区别、来源、边界例和新例判断 | 篇幅增长、术语增加 |
| 期望／目标 | 主体确认倾向与采纳，能区分状态和手段 | 引导得到“标准答案” |
| 标准与决策 | 规则可用于例子，依据可追溯，保留硬条件和未知 | 任意加权总分、事后合理化 |
| 因果与信念 | 竞争解释、区分预测、材料适配 | 流畅的故事 |
| 共享与分歧 | 指定范围的复述、新例、可准确描述对方 | 完全一致、重复原句 |
| 委派与协调 | 请求状态、有效授权、可开始、异常与验收过程 | 清单完整但没有执行条件 |
| 执行与反馈 | 产物／日志／现实结果、标准核验和有效修订 | 说已完成、仅提交文件 |

## 最小使用记录

Task ID／日期；主体和角色；输入与缺口；调用 OP/PR；预期 Transition；实际输出；检查材料；无变化／失败／改善；成本；下一步。敏感信息按实际用途限制记录。个人不必为每次自问建立复杂表格；先保留能检验关键判断的最小材料。

## 可实施的验证设计示例

**研究问题**：PR03 是否帮助学习者写出可用于判断的评价标准，而不只是列维度？此为待检验设计，不是已经完成的实验。

1. 招募与任务规模依据研究目标、可行性和事前功效分析（根据拟检测的差异、变动程度和检验要求估计样本需求）确定，不凭空指定“足够”的人数。
2. 使用等价但不同任务，比较常规提示与 PR03；需要分离语言形式效果时匹配时间、信息与关注程度。采用随机分配或可论证的交叉设计（参与者经历不同条件并处理顺序影响），并处理练习和顺序影响。
3. 事前规定主要结果：独立评审能否依据产物对新例作一致且任务适切的判断；同时记录遗漏硬条件、编造材料、耗时和负担。评审标准自身也需试用。
4. 评审尽量不知道条件；报告一致性、所有失败、缺失数据处理、效果估计及不确定性。将“更长”或“更满意”单独记录，不替代主结果。
5. 加入延迟和陌生任务，以减少提示的条件检查是否仍能独立形成标准。只支持任务与人群范围内的结论。

对于无法随机化的真实协作，记录基线、同期变化和竞争解释，明确因果识别较弱；不把前后不同直接归因于 CLE。

## 置信与校准

主张—材料关系的修订可作为工程上的判断修订。**统计校准**需要一组有可判定结果的预测及其置信度，分析置信与正确率关系；单次问“有多确定”并不足够。元认知偏差关注总体自信高低，敏感性关注信心能否区分正确与错误判断，效率关注相对于特定任务表现水平的监控能力；这些不是同一个测量，参见 [SRC08](../sources/VERIFIED_SOURCES.md#src08)。

## 停止与修订

达到当前任务最小充分状态后停止；若新增步骤没有改善检查结果却显著增加成本，缩减或替换。拒绝、保留分歧、暂缓和信息不足均可为有效结果。失效要定位到输入、模式、机制假设、顺序、环境或判断规则，避免把所有失败归为“使用者没理解”。

当前工程基线已完成结构与边界设计检查，未执行用户试验、因果效果研究或迁移研究。后者是验证工作，不影响工程基线已形成这一状态。

## 无前测、已有能力与代理产物

无可比较前状态时不把它默认成“不会”。当前产物与当前独立表现各自评估；已有能力在本次被调用，也可能满足任务，但不算本次能力增量。协助者、AI或团队产物不能自动作为个体掌握的测量。

评审时至少分开：是否进行操作、是否得到产物、目标状态的支持范围、停止方式和成本；需要效果或迁移结论时再增加相应设计。合适的拒绝或暂停可为任务的有效处理，但未发生的Transition保持未达成或未知。

失效诊断遵从[失效分析](FAILURE_ANALYSIS.md)。没有用户试验时，训练练习的预期答案与案例检查只支持设计解释，不报告通过率或实际学习收益。

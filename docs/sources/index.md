# 来源与证据管理

使用[证据规范](../EVIDENCE_SPEC.md)管理主张，使用[核验文献](VERIFIED_SOURCES.md)定位来源。每次引用至少记录：主张、支持段落或摘要、读取深度、对象与任务、适用边界、冲突或未知。

理论提供论证；原始实验报告具体观察与比较；综述组织既有研究；元分析统计汇总多项研究结果；书目记录只确认作者、题名等标识。这些不能简单排成质量等级。E 标签表示当前证据类型和范围，研究质量另行检查。仅核验书目时不为效果主张赋予实证支持。

不要复制受版权保护的全文到发布包。保留公开来源链接、必要书目信息和适量转述。未读取到内容的页面不能通过标题猜测结论。

[历史对话引文审计](conversation-citations.md)记录原有引用的去向。新增来源与新增工程定义是两种独立修改。

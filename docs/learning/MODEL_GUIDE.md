# Model：四模型导读

模型是组织观察对象、有关状态与变化的分析框架。表征是对对象或经验的表示，认知关注主体当前能识别或使用什么，共享互动关注各方共同持有或理解什么，语言行动关注按规则提出或改变的请求与安排。

四模型将认知语言工作组织为四种可重叠的观察视角：表征、个人认知、共享互动、语言行动。它们不是四个独立脑模块，也不是一次任务的四个必经步骤。

| 模型 | 观察什么 | 要学会的区别 | 进入接口 |
| --- | --- | --- | --- |
| M1 表征 | 讨论所指怎样明确，对象怎样被描述、区分、归类及表达 | 表征包含的内容与世界真实情况分别核对 | [9个接口](../models/M1.md) |
| M2 个体认知 | 主体怎样识别、比较、解释、评价、采纳及选择 | 他人或AI的产物与本人能做的事分别检查 | [35个接口](../models/M2.md) |
| M3 共享互动 | 各方共享了什么，含义、模型和分歧怎样处理 | 理解、同意及共同错误分别判断 | [9个接口](../models/M3.md) |
| M4 语言行动 | 按既有规则建立或修改请求、任务、承诺、责任和权限 | 接收、接受、执行、核验与社会关闭分别判断 | [29个接口](../models/M4.md) |

## 同一事件怎样读

构造情境：“请你周五交初稿。”M1看文字是否清楚表示交付和时间；M2看本人能否理解任务并评价条件；M3看双方是否有对同一含义的确认依据；M4看请求是否成立、是否接受以及后来是否完成。只知道这句话存在时，其余状态可能未知。

个人思考可只涉及M1/M2。M4包含社会或技术任务关系，不能把所有带行动动词的个人计划都归到M4。现实执行和结果需外部材料；四模型以此连接反馈。

## 从模型到接口

M1的[所指](../models/M1.md#referent)组检查名称或描述具体指向什么；M2的[对象](../models/M2.md#object)组组织主体对认知内容的聚焦、识别、区分和界定。同一事物可以从这两个视角检查，两个组名分别提示各自关注点。

先辨认观察对象，再看该模型下哪个变化方向与问题相符。例如M1下“具体讨论什么”是[R-C2](../models/M1.md#r-c2)，“选哪些特征”是R-P1，“怎样表达”是R-P5；M2下“本人关注哪里”是C-P1。名称相近时用完成检查辨别。对象叫什么还不知道时，指认从注意线索和日常描述进入，不要求先给名称；其他形成接口同样先看材料起点和具体方法。

四模型正文各用一段说明解释接口之间的联系，并以子标题和阅读顺序组织接口。分组用于帮助理解，标题采用固定名称，原接口ID与定义保持可追溯。命名及范围见[术语表](../GLOSSARY.md)。

本版为每个接口提供操作入口、最小做法及语言模式的核心句与展开。核心句帮助记住方向，展开提供可直接使用的表达，完成检查说明结果依据；先把这些内容连起来理解，再按需读机制与边界。查看[全部学习连接](INTERFACE_PATHS.md)。原“五个心智模型”作为理解工程运行的[辅助说明](../MENTAL_MODELS.md)，不计为五个正式模型。

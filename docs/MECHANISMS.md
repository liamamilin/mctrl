# Mechanism Map｜过程解释与映射

机制解释变化可能怎样产生，帮助理解与诊断；它不替代算子的方法入口，也不构成五层学习主线的强制中间层。


机制是对变化怎样产生的过程说明；未取得相应依据时保留为候选解释。机制家族是相关过程解释的分组索引，不把一个家族当作单一已测得心理过程。模型中的映射均是工程候选；有文献支持的局部现象另列来源，不能把其等级直接赋给全部组件。

例如，问句要求把两个方案按同一方面并置，是操作；假说是“并置使相关区别更容易进入比较”；观察材料应说明区别是否被辨认，以及是否只是直接给出了答案。由操作名到过程解释，中间需要这个可检查的假说；仅写“比较机制”没有补上它。以下“将”“使”等过程描述在未有直接依据处均按候选阅读，不登记为已经发生。

<a id="me01"></a>
## ME01. Attention Direction / Search Allocation

语言提示将任务注意指向特定对象，并限定接下来搜索哪些信息。映射 C-P1/C-P9/C-P13、R-P1。使用问句可尝试这种变化，但“每个问题必然重新分配注意”的强命题不采用。本版为 E0 过程假设；检查聚焦迹象和遗漏成本。

<a id="me02"></a>
## ME02. Comparison / Categorization / Structural Mapping

分别涉及对照、识别特征和映射关系，不假定三者是同一机制。映射 R-P2/R-P3/R-P4、C-P3—C-P7。提出差异／相似请求后，检查是否产生可使用区别及错误类推。本版映射 E0；命名基本认知活动不等于解释了其神经或计算过程。

<a id="me03"></a>
## ME03. Encoding / Externalization / Retrieval

分别组织表达、外化（将内容形成可查看的外部记录）和提取（重新调用有关材料）。映射 R-P5/R-P6/R-P7、C-P2。外化可以改变任务的信息处理要求；[SRC07](sources/VERIFIED_SOURCES.md#src07)提供相关综述。本版不据此宣称写下来一定提高记忆或理解；编码、压缩和概念命名的具体映射仍 E0。

<a id="me04"></a>
## ME04. Metacognitive Monitoring / Confidence Representation

注意自身判断过程、依据和不确定性。映射 C-P2/C-P10/C-P19/C-P20、C-C11/C-C12。[SRC08](sources/VERIFIED_SOURCES.md#src08)区分元认知偏差、敏感性与效率，支持分开测量，而非以自述替代指标。操作后的可靠性改善仍需实验或结果记录。

<a id="me05"></a>
## ME05. Contextual Valuation / Framing

候选、目的和表述参与主观评价。映射 C-P7/C-P15/C-P17/C-P21、C-C8/C-C9/C-C10。[SRC02](sources/VERIFIED_SOURCES.md#src02)、[SRC03](sources/VERIFIED_SOURCES.md#src03)、[SRC12](sources/VERIFIED_SOURCES.md#src12)支持局部框架、偏好构造与决策一致化研究。不从一个问法反应确定主体稳定偏好，也不把改变倾向等同于提高判断质量。

<a id="me06"></a>
## ME06. Alternative Generation / Counterfactual Construction

调用记忆、类比或情境改写生成候选。映射 C-P8/C-P11/C-P12/C-P16。Removal 等算子属于此类工程假设。想象 X 不存在时仍有结果，不能单独证明 X 在现实中非必要；反事实结果依赖模型。效果与必要性推断均按 E0 处理。

<a id="me07"></a>
## ME07. Prospective Simulation

组织未来事件或状态表征；这里情景性（episodic）表征设想具体个人事件，一般知识性（semantic）表征描述未来的性质或关系，二者不混为同一种想象。这是辅助阅读区分，相关个人与非个人未来思考的研究用法可查[原研究摘要](https://pubmed.ncbi.nlm.nih.gov/27252632/)，不据此新增CLE效果主张。映射 C-P16、C-C6/C-C13。[SRC04](sources/VERIFIED_SOURCES.md#src04)支持未来事件模拟在指定跨期选择任务中的效果，[SRC05](sources/VERIFIED_SOURCES.md#src05)提供概念基础。它们不验证所有期望状态构造，亦不证明理想画面自动促成行动。

<a id="me08"></a>
## ME08. Explanation / Evidence Appraisal / Model Testing

分别组织候选解释、证据相关性与区分竞争解释的测试。映射 C-P11/C-P12/C-P14/C-P19、C-C2/C-C3/C-C9/C-C11。需用关系、预测、反例和实际观察，而不是把“能解释”当“是真的”。[SRC09](sources/VERIFIED_SOURCES.md#src09)支持特定社会判断任务的反向考虑干预；不保证普遍去偏。[SRC10](sources/VERIFIED_SOURCES.md#src10)仅题录确认，不作为本版效果依据。

<a id="me09"></a>
## ME09. Goal Regulation / Adoption / Planning

分别组织目标采纳、资源投入、手段计划和线索—行为绑定。映射 C-P18/C-P21、C-C7/C-C10/C-C13/C-C14。[SRC06](sources/VERIFIED_SOURCES.md#src06)支持 goal intention 与 implementation intention 的区分；[SRC11](sources/VERIFIED_SOURCES.md#src11)为目标设置研究索引。C-P18 作为 CLE 独立接口仍 E0，不等同于验证了一个单一目标采纳机制。

<a id="me10"></a>
## ME10. Grounding / Interactional Repair

共享确认（grounding）是共同提供和检查当前目的所需理解依据的过程；互动修复是根据反馈定位并修正误解或歧义。映射 I-P1、I-C1—I-C8、B-C2。[SRC01](sources/VERIFIED_SOURCES.md#src01)提供原理论文本依据。共享程度是对任务的充分程度，不是完美一致；CLE 的特定模式、停止条件与错误率仍需检验。

<a id="me11"></a>
## ME11. Situated Interpretation / Pragmatic Inference

语用推理是根据语境、角色、前文和语言形式，判断表达指什么、在互动中要做什么。映射 I-C2/I-C3、A-P1、B-C2/B-C3/B-C7。本版作为理论相关过程家族登记；不宣称语言形式足以决定功能。[SRC01](sources/VERIFIED_SOURCES.md#src01)说明理解与互动的关系，但不承担全部语用推理理论。

<a id="me12"></a>
## ME12. Constitutive Rules / Social-State Update

构成规则说明何种条件下某事件算作有效关系或状态，例如什么算任务已接受。根据有效规则，将请求、承担、认可、授权或关闭事件解释为社会状态更新。映射 M4 全部条目。这里首先是过程与制度规则的工程描述，效果 E0；不是把“承诺形成”再叫作同名机制就得到因果解释。需检查角色、来源、认可与真实执行条件。

## 映射检查

每个映射至少回答：要解释哪个前后变化、提出什么过程、什么观察可支持或推翻、还有什么替代解释、研究材料与当前任务有何差别。无法回答时，保留为未验证假设，不装成机制已经成立。

## 从家族名到可检验过程

下表提供每个家族的一种工作假设，均为 E0 的工程示例。迹象只是可能的过程材料，单个迹象不证明机制；来源对局部主张的支持仍按前文限定。

| 家族 | 当前可提出的候选过程 | 可取得的迹象 | 需要排查的替代 |
| --- | --- | --- | --- |
| ME01 | 提示限定搜索对象，使相关材料进入关注 | 输出的对象、搜索记录和遗漏变化 | 新资料、时间增加、原已聚焦 |
| ME02 | 并置对象和维度，使区别或关系可辨认 | 对照前后是否能指认同一维度的差异 | 直接提供答案、术语重复 |
| ME03 | 外部记录让所需材料更易重新调用 | 调用路径、遗漏、查找成本 | 信息更多而非外化本身 |
| ME04 | 对依据和未知的提示使判断被重新检查 | 依据变化、独立错误检查 | 事后理由、更保守回答 |
| ME05 | 表述与参照改变某维度的权重或评价 | 不同形式下的选择、理由和条件 | 内容改变、不同受众、新证据 |
| ME06 | 改变前提或条件生成不同候选 | 候选差异、模型条件、区分预测 | 同义改名、未经查证的故事 |
| ME07 | 构造未来情境使部分后果更可考虑 | 所考虑的后果及其依据、选择变化 | 仅增加篇幅、理想化或资料增加 |
| ME08 | 比较主张、材料与预测后修订解释 | 支持关系、区分材料及更新依据 | 说服压力、引用数量而非内容 |
| ME09 | 采纳对象或绑定线索组织后续行动 | 采纳记录、具体条件、实际触发行为 | 原有习惯、资源变化或他人推动 |
| ME10 | 反馈定位误解，使共同使用内容得到修正 | 误解位置、新例、版本与确认范围 | 单方复述、记忆、实际仍不同 |
| ME11 | 前文和角色帮助解释所指与行动功能 | 不同语境下的解释差异 | 语言内容也同时变化 |
| ME12 | 有效规则把事件登记为社会关系更新 | 来源、角色、认可和生效记录 | 只有声明、无效来源或无接收依据 |

ME12 首先解释规则如何判定关系，不因此证明某心理因果机制。跨家族的同一迹象可以支持多种解释；研究需进一步选择能区分它们的材料。

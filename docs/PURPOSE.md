# 核心目的

认知语言工程（Cognitive Language Engineering，CLE）的核心目的，是提升人对语言的主动控制能力，使语言更有效地服务于思考、表达、影响、协作与行动。

这里的主动控制，是能根据当前目的和状态选择、设计、检验与修订语言操作，而不是只依靠习惯、临场灵感或记住一些固定问句。

人的目的 → 任务与状态识别 → 语言设计与使用 → 认知／互动／行动状态变化 → 实际结果 → 反馈与修订。

这条箭头线说明希望怎样组织工作，不说明每次使用都会产生变化或改善。语言可以用于把材料写清、比较解释、检查理解或提出请求；能否得到相应结果须逐项取证。前面的“提升”“更有效”是本体系追求的目的，是否实现按[评估规范](evaluation/EVALUATION.md)检查。

语言学、认知科学、心理学、修辞学、哲学、HCI 和 AI 研究为这条主线提供材料。进入核心体系的内容需要说明它支持哪个具体主张、适用于什么边界，以及怎样判断是否有帮助。

本体系服务于人的能力提升。影响他人时须保留其目标、偏好与拒绝空间；人机协作时须区分模型生成的文本、真实理解、授权与实际执行结果。

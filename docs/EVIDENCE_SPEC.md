# Evidence：主张、来源与外推

主张是具体提出的说法；来源说明材料来自哪里；证据说明这份材料为何支持、反驳或限制该说法。外推是将结论用于未直接研究的任务、人群或情境，须说明适用依据。

## 证据等级的保留与修正

| 等级 | 本版定义 |
| --- | --- |
| E0 | CLE 内部假设、工程约定或示范，尚无该效果主张的验证 |
| E1 | 有理论论证或可追溯实践记录；不能以“很多人使用”替代有效性 |
| E2 | 有直接相关的实证研究；需列任务、样本、设计与局限 |
| E3 | 有相关综述、汇总或重复证据；仍需判断质量、异质性与适用范围 |
| E4 | 在明确范围内有高质量、跨方法且较一致的证据；本版不授予任何组件 E4 |

等级描述支持类型的粗略索引，不是自动置信度计算，也不是“有元分析（汇总多项研究结果的统计分析）就必定高质量”。全文／摘要／题录核验范围另列。

## 三种不同主张

1. 现象主张：某种条件下观察到框架效应或外化行为。
2. 机制主张：某过程解释该现象，需要过程证据或能区分替代解释的设计。
3. CLE 干预主张：某 Operator／Pattern／Protocol 在指定任务中改善结果。

现象有证据，不自动证明机制；机制有相关研究，不自动验证 CLE 的包装、顺序或效果。文档规范被接受也不提升效果等级。

例如，资料支持某种表述下选择分布不同，只能支持所研究条件下的差异；要说明为何不同，需要过程与替代解释材料；要说明本书的一个协议使判断更准确，又需该协议、对象及正确性检查。三个主张需要的材料不同，不能靠连续引用同一来源跨过去。

## 来源卡与核验

来源卡记录题名、作者、年份、标识、读取范围、支持的具体主张、定位、证据类型、局限、对应组件和不支持的外推。优先论文、作者材料和官方文档。全文不可读时，以已读摘要限定使用范围。

来源不支持旧主张时，修改主张或撤回引用，保留原因。本版纠正了把 PMID 15102143 直接当成“选择之后导致重新评价”的引用：原论文报告决策过程中的偏好一致化，变化可发生于选择承诺之前，不能直接承担只有事后变化的因果结论。

## 信念调整与统计校准

C-C11 首先支持依据证据调整信念、明确范围和未知。输出 70% 或降低自信不等于统计校准；后者需要一组可核验事件上的预测与结果对应。Brier分数用于衡量概率预测与实际结果的差距，可靠性图用于对照预测概率与观察频率；它们需要一组可核验事件的结果与概率记录，是专业测量选项，不是学习主线的前提。释义核对可见[ECMWF概率预报指标说明](https://confluence.ecmwf.int/spaces/FUG/pages/673551875/Section%2B12.B%2BStatistical%2BConcepts%2B-%2BProbabilistic%2BData)与[Met Office可靠性图说明](https://www.metoffice.gov.uk/research/climate/seasonal-to-decadal/gpc-outlooks/user-guide/interpret-reliability)；这些来源仅帮助解释测量词，不支持CLE效果。

## 当前证据结论

已核验来源支持若干局部研究现象或理论，不支持“CLE 整套体系已有效”。[来源登记](sources/VERIFIED_SOURCES.md)与[旧引文审计](sources/conversation-citations.md)明确读取范围。全体系组成关系、操作卡与协议效果仍是可检验工程设计。

## 证据落到主张，不落到组件名称

最小主张记录：具体说法与范围、主张类型、来源及定位、读取深度、支持／冲突／未知关系、外推限制。理论依据、现象材料、过程证据和工程效果分别判断；不为每次自问强制建立全部记录。

例如，SRC02 支持指定决策表述的选择差异，不直接支持“PR13 提高用户判断”。同一来源可以支持一个局部现象，而对更宽的机制或协议效果没有直接支持。资料重复转述不自动增加独立支持。

只有事后产物时，说明产物；有主体当前表现时，说明该范围表现；有可比较前后材料时，说明观察到变化；适当比较设计才进一步支撑效果归因。当前来源读取范围沿用已核验记录，本次审查未把摘要或题录升级为已读全文。
